# Kiyabo CLI v1.0.0 – First Release

**Standalone CLI for Tanzanian School Exam Management**

## Features
- `upload` – Excel → Access
- `export` – Ranked results to formatted Excel
- `process` – Auto-rank with INC handling
- Full color console + ASCII banner
- No Python required

## Supported Levels
- [x] A-Level (full)
- [ ] O-Level (ready)
- [ ] Primary (ready)

## Download
- [32-bit](kiyabo32.exe) – for older machines
- [64-bit](kiyabo64.exe) – for modern Windows
